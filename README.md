# CRUD API generator

Create a REST full backend API for your project:
- any database (PostgreSQL, MySQL, Oracle, SQLite, MariaDB, etc.);
- any protocol (REST, SOAP, OData, Protobuf, WebSocket, etc.);
- any platform (Node.js, PHP, Java, etc.);
- any format (JSON, XML, etc.)

## Features (in progress)

- standard operations: create, read, update, delete;
- complex search filters and multi-sort;
- audit logging / data versioning;
- manual ordering for lists;
- optimistic locking;
- row-level security (RLS);
- data masking (PII protection);
- field projection;
- RBAC / ABAC role model;
- bulk operations (sync / async);
- save and resume download for files;
- export data to Excel / CSV;
- request batching;
- auto-installer;
