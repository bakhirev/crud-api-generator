# Инструкции для агента

Новый код — Node.js в `nodejs/`. Контракт модулей — `spec/`. Каталог `old-document/` — архив прежнего PHP CRUD API, игнорировать.

## Перед правкой

1. Найди спецификацию модуля в `spec/` и реализуй её. Если спека и код расходятся, следуй спеке и поправь код.
2. Для уже существующего модуля копируй стиль соседних файлов в `nodejs/`.

## Код

- CommonJS: `require` / `module.exports`. Один модуль — один файл в каталоге, который соответствует `spec/` (`components/`, `apps/`, `configs/`).
- Минимум кода. Предпочитай встроенные методы языка. Стремись к сложности O(1), где это уместно.
- Неверные входные данные не должны ронять процесс необработанным исключением: верни пустой или ошибочный результат в том виде, который задаёт спека.
- Не добавляй зависимости, тесты и файлы, которых задача не требует.

## Карта

| Путь | Роль |
| --- | --- |
| `spec/components/` | Контракт переиспользуемых модулей |
| `spec/apps/` | Контракт приложений |
| `spec/configs/` | Формат JSON-описаний |
| `nodejs/components/` | Реализация компонентов |
| `old-document/` | Архив PHP: маршруты, SQL, конфиги сущностей |
