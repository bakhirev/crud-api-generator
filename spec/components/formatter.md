# formatter

Приводит строку к одному из регистров. Парсер вызывает его при записи JSON, см. `../apps/parser/dbServer.md`.

## API

`format(value, type)`

`value` - исходная строка.
`type` - `snakeCase`, `camelCase`, `PascalCase`, `kebabCase`.

`camelCase` - это `lowerCamelCase` из REST. `PascalCase` - CamelCase, каждое слово с заглавной буквы.

Не строка, пустая строка или неизвестный `type` - пустая строка.

## Разбиение на слова

В слово входят буквы `A-Za-z` и цифры. Остальные символы - разделители и в слово не входят.

Дополнительно слово кончается перед заглавной буквой, если перед ней строчная или цифра (`testUsers` → `test`, `Users`).
Несколько заглавных подряд делятся перед последней, за которой идёт строчная (`HTMLParser` → `HTML`, `Parser`).

## Сборка

Пустой список слов - пустая строка.

`snakeCase` - слова в нижнем регистре через `_`.
`camelCase` - первое слово в нижнем регистре, каждое следующее с заглавной первой буквы, остальные буквы слова в нижнем регистре.
`PascalCase` - каждое слово с заглавной первой буквы, остальные буквы слова в нижнем регистре.
`kebabCase` - слова в нижнем регистре через `-`.

## Примеры

`test_users` и `camelCase` → `testUsers`
`testUsers` и `snakeCase` → `test_users`
`test-users` и `PascalCase` → `TestUsers`
`TestUsers` и `kebabCase` → `test-users`
