# Набор компонентов, для выполнения разных типов запросов к БД

## Аргументы на входе

`context` - сквозной обьект данных (см. `context.md`)
аргументы, необходимые для генерации сответствующего запроса (например: массив колонок, фильтров и т.п.)

## Выходной формат

См. `query` из `../Connector.md`

## Общий алгоритм работы

- создать подключение к БД;
- сформировать запрос (см. конкретный компонент);
- выполнить его;
- вернуть результат;
