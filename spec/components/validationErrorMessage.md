# Класс ValidationErrorMessage

Накапливает сообщения об ошибках. Склеивает их в одну строку.

## Структуры данных

### Сообщения об ошибке
```
  messages: string[]; // Сообщения об ошибке
  property?: string;  // Префикс результирующего сообщения
```

## API модуля

Экземпляр класса инициализируется с пустым массивом сообщений и префиксом (передается в конструктор).

### Добавление ошибки

На входе строка или "правило валидации" (см ./validation.md)

Если строка не пустая, то она добавляется в `messages`
Если строка пустая, то она игнорируется.
Если правило валидации, то по нему формируется строка и добавляется в `messages`

### Получение итогового сообщения

Входных аргументов нет.
Метод возвращает строку:
Если `messages` пуст, то пустая строка
Иначе значения в `messages` склееные через пробел. Если указан property, то он префикс `property: messages`


## Формирование строки ошибки из "правил валидации"

Если есть property, то `Значение property должно быть condition value`.
Если нет property, то `Значение должно быть condition value`.
Если value строка, то в кавычках.
