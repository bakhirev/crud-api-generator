# sendResponse

Отправляет ответ на http запрос

## Структуры данных

### Input arguments

`response` - обьект ответа (если нужен для данной среды исполнения).

`type` - string, протокол передачи данных (soap, xml, json, multipart/form-data, OData, protobuf). Правила обработки каждого протокола хранятся в отдельном файле.

`code` - number, http-код ответа. По умолчанию 200.

`body` - json, тело ответа. В зависимости от `type` может быть преобразован в разные форматы.
