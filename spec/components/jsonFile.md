# Работа с JSON файлами

Читает и сохраняет файлы с JSON

## Методы

get - принимает строку с адресом файла. Читает файл в utf-8. Переводит текст из файла в JSON обьект. Если не получилось вовзращает null;

set - принимает строку с адресом файла и данные. Записывает данные в файл (JSON приводт к строке, 4 пробела для форматирования JSON). Если путь к файлу не существует - рекурсивно создает все необходимые директории.

## Особенности реализации

Ошибки не должны приводить к падению скрипта.
